## Tech notes for development

- Pure static to SERVE: no build step and no dependencies are needed to view, host
  or deploy this bundle. Everything committed is directly servable.
- One OPTIONAL developer step exists: `node build-css.mjs` regenerates the
  `assets/nf-bundle-*.css` files after you edit any fix-layer stylesheet under
  `assets/**/`. The bundles are committed, so you only run this if you changed a
  source. `node build-css.mjs --check` fails if a bundle is stale — useful in CI.
  See the header comment in `build-css.mjs` for why there are six bundles and not one.
- Shared chrome CSS in `chrome.css` (linked from each page).
- Page-specific styles in inline `<style>` block in each HTML.
- Internal nav hrefs rewritten to point at sibling pages.
- Asset paths mirror source URL structure verbatim (per scope §K.1).
- Tracking scripts (GA, GTM, FB pixel, Hotjar, etc.) stripped at emit.
